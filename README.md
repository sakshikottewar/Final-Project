# Smart Facility Management Dashboard

A full-stack web application for managing facilities, inspections, and complaints through a centralized dashboard.

The system allows facility administrators to monitor facility information, conduct inspections, manage complaints, and view important operational statistics from a single interface.

---

## 📌 Project Overview

The **Smart Facility Management Dashboard** provides a centralized platform for managing facility-related operations.

Instead of maintaining facility records, inspection details, and complaints separately, the application brings all information together into one dashboard.

### Main Modules

- Dashboard
- Facility Management
- Inspection Management
- Complaint Management
- Department Management
- API-based Backend
- PostgreSQL Database
- Responsive Web Interface

---

## 🎯 Problem Statement

Facility management often involves handling multiple types of information such as:

- Facility details
- Facility locations
- Departments
- Inspection records
- Inspection scores
- Maintenance complaints
- Complaint priorities
- Complaint statuses

Managing this information manually or through separate systems can make it difficult to track facility conditions and identify issues quickly.

The Smart Facility Management Dashboard provides a centralized system to simplify these operations.

---

## 💡 Proposed Solution

The application provides a web-based dashboard where users can:

- View facility statistics
- Add and update facilities
- View facility details
- Record inspections
- Track inspection scores and statuses
- Register complaints
- Track complaint priorities
- Update complaint status
- View recent inspections
- Store data securely in PostgreSQL
